# Project JARJAR

Godot 4.7.2-stableで開発する、見下ろし型3DローグライトのWindows向けMVPです。

3本の自動攻撃武器と、武器・プレイヤー全体を強化する3個のお守りを組み替えながら進む構成です。同レアリティのアイテム3個は、上位レアリティの武器またはお守り1個へ合成できます。

現在はbalance revision 3の実装とGDScript回帰まで完了し、ユーザーによるエフェクト・文言等の最終調整を待っています。正式な5人×3runのプレイテスト対象はまだ固定していません。
