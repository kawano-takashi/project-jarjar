# Project JARJAR

Godot 4.7.2-stable Standardで開発する、Windows向けの見下ろし型3Dサバイバル・ローグライトです。
Compatibility rendererを使用します。

32×32mのアリーナで追尾核Lv1から開始し、移動に集中しながら自動攻撃とレベルアップ3択で
20分間ビルドを成長させます。武器5枠とパッシブ5枠を組み合わせ、戦闘時間20:00に出現する最終ボスを倒すとクリアです。
ボス戦はさらに1〜2分を目安とし、ポーズや強化選択の時間は戦闘時間に含めません。
名称、形状、演出は幾何学テーマの独自表現です。

## 遊び方

- WASD、矢印、方向パッド、左スティックで画面基準の移動。攻撃は自動です。
- 敵の経験値結晶でレベルアップし、戦闘を停止した最大3択から強化を選びます。
- 基本武器Lv8と対応する触媒Lv1以上を所持すると、進化可能宝箱で進化できます。1runの進化は最大4回です。
  触媒はパッシブで、最大Lv不要・進化後も消費されません。初進化の目標は7〜9分、通常強化完了は16〜18分です。
- エリートは2:00から18:00まで2分ごとに計9体出現します。2・4・6分のエリートは金色の四角い通常宝箱、
  8分以降のエリートは水色の尖った進化可能宝箱を落とします。
- 通常宝箱は所持装備を1段階強化し、強化先がなければ全回復します。
  進化可能宝箱は条件を満たす武器を必ず1つ進化させ、条件未達や進化上限では通常強化・全回復に移ります。
  箱の種類はエリートの出現予定で決まり、撃破や回収を遅らせても変わりません。床に残して温存できます。
- 通常敵はプレイヤーを中心とした画面四辺の10〜12m帯から出現します。
  通常敵とエリートは接触追跡を行い、最終ボスは予告付きの放射弾を使います。
- 横断群れは地面の帯と矢印で進路を予告し、その進路を直進します。撃破して穴を開けることもできます。
  同時に来る進路は1つで、予告中・通過中の追加予定は見送ります。20:00には通常敵・群れ・群れの予告を整理します。
- 接触と敵弾は毎combat tick（固定60Hz）、倍率適用後の最大威力1件だけを適用します。
  レベルアップから直接戦闘へ戻る場合だけ、次の45 combat tickを保護します。
- 初回の移動案内を完了すると、以後のランではチュートリアルを省略します。設定から再表示できます。

## 開発と検証

PATH上のGodot 4.7.2-stable Standardで `project.godot` を開いてください。
実装仕様と数値は `src/`、`data/`、`tests/` を参照してください。

- [ビルド・テスト・作業上の制約](AGENTS.md)
- [20分の進行・成長・群れの設計意図](docs/balance-intent.md)
- [プレイテストの成功基準・手順・結果](docs/playtest.md)

通常戦はmanifestから読み込む20区間のResourceで構成し、区間の整数tickの合計からボス出現時刻を求めます。
難易度の測定器は各区間末とボス出現後5分までを対象とし、各進化の時刻・通常強化完了時刻・未到達件数を出力します。
`difficulty-runs.csv` にrunごとの時刻、`difficulty-growth.csv` に方針・進化段階ごとの到達数と中央値を記録します。
測定は調整の参考資料です。性能試験・Release検証・QA・人間のプレイテストは、最終調整完了の明示後に既存手順で実施します。
