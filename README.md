# Project JARJAR

Godot 4.7.2-stable Standardで開発する、Windows向けの見下ろし型3Dサバイバル・ローグライトです。
Compatibility rendererを使用します。

30×30mのアリーナで追尾核Lv1から開始し、移動に集中しながら自動攻撃とレベルアップ3択で
10分間ビルドを成長させます。武器5枠とパッシブ5枠を組み合わせ、10:00に出現する最終ボスを倒すとクリアです。
名称、形状、演出は幾何学テーマの独自表現です。

## 遊び方

- WASD、矢印、方向パッド、左スティックで画面基準の移動。攻撃は自動です。
- 敵の経験値結晶でレベルアップし、戦闘を停止した最大3択から強化を選びます。
- 基本武器Lv8と対応する触媒Lv1以上を所持すると、エリートの宝箱で進化できます。
  触媒はパッシブで、最大Lv不要・進化後も消費されません。
- エリートは2:00、4:00、6:00、8:00に出現します。宝箱は進化・通常強化・全回復のいずれか1効果です。
- 通常敵はプレイヤーを中心とした画面四辺の10〜12m帯から出現し、50体の小型群れも横断します。
  通常敵とエリートは接触追跡を行い、最終ボスは予告付きの放射弾を使います。
- 接触と敵弾は毎combat tick（固定60Hz）、倍率適用後の最大威力1件だけを適用します。
  レベルアップから直接戦闘へ戻る場合だけ、次の45 combat tickを保護します。
- 初回の移動案内を完了すると、以後のランではチュートリアルを省略します。設定から再表示できます。
